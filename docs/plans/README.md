# Plans

How the work gets sequenced and handed to agents.

- [`roadmap.md`](roadmap.md): the big phases, in order.
- **Build plans:** for a large approved spec, an agent may write `NNN-short-name-plan.md` here:
  an ordered checklist of small steps, each one testable and committable alone. Tick steps as
  they're done so a new agent session can pick up where the last one stopped.
