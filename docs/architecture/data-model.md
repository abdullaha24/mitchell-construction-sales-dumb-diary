# Data model (Google Sheets)

> Status: **Draft v0.2** (2026-11-04), updated after the owner interview. Still a draft until the
> phase 1 spec is approved. The tabs and headers act as the app's database schema. **Any change
> here must be made in the same change as the code.**

Two spreadsheets (ADR-0005):

| Spreadsheet | Owned by | App access |
| --- | --- | --- |
| **Mitchell Sales Meta-Data** | Owner, edited by hand | **Read only** |
| **Sales Diary** | The app | Read and write |

Conventions:
- Row 1 of every tab is the header. Code finds columns **by header name**, never by position.
- IDs are generated by the app and never reused.
- Timestamps are written by the server, never typed by people.
- The salesman ID everywhere is his `Rep` code from `Rep_Mapping` (e.g. `RIA`).
